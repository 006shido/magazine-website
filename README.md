# Editor's Desk - Magazine Website

A sleek, modern editorial and digital magazine showcase website built with responsive HTML, CSS, and JavaScript.

🌐 **Live Demo**: [https://006shido.github.io/magazine-website/](https://006shido.github.io/magazine-website/)

## Features

- **Dark & Light Mode**: Dynamic color scheme with high-contrast typography and subtle filmic accents.
- **Hero Carousel & Timeline**: Interactive header showcase with animated timeline transitions.
- **Editorial Portfolio & Issues**: Visual magazine issue cards, interactive previews, and modal reader view.
- **Services & Production Notes**: Clear breakdown of editorial, art direction, and publishing capabilities.
- **Fast & Dependency-Free**: Pure HTML5/CSS3/vanilla JS with Google Fonts.

## Getting Started

Simply open `index.html` in any modern web browser, or serve with any static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```
